# Fallout 4 기본 게임의 플레이 구조

이 문서는 레퍼런스 분석 자료다. 아래 분류와 프로토타입 예시는 SoloRPG의 기능을 검토할 때 참고할 후보로 정리했다.

Bethesda가 소개한 기본 게임 기능을 바탕으로, 플레이어가 반복하는 행동과 다음 행동으로 이어지는 결과를 정리했다. 표의 루프와 연결 관계는 플레이 구조에 대한 분석이다. 조사 범위는 기본 게임이다.

| 플레이 영역 | 반복 흐름 | 다음 플레이로 넘어가는 결과 |
| --- | --- | --- |
| 탐험과 수집 | 목적지나 흥미로운 장소 발견 → 접근해서 조사 → 장비·물자 획득 → 다시 이동 | 새로 찾은 장소와 목표, 장비와 제작 재료 |
| 전투 | 위협 발견 → 실시간 조준 또는 V.A.T.S. 활용 → 결과 확인 → 전리품 수집 또는 이동 재개 | 소모한 탄약과 체력, 전리품, 통과 가능한 경로 |
| NPC·퀘스트·세력 | NPC 만나기 → 대화나 의뢰를 통해 목적 파악 → 행동하고 퀘스트 진행 → 다음 목표 발견 | 퀘스트 진행 상태, 함께할 동료, 세력과의 관계 및 접근 가능한 목표 |
| 성장과 장비 | 경험치로 성장 → 능력치·퍽이나 장비에 투자 → 달라진 방식으로 상황에 접근 | 전투·은신·대화 등에서 달라지는 선택과 효율 |
| 제작과 개조 | 물자 수집 → 제작대에서 재료 사용 → 장비·소모품 제작 또는 장비 개조 → 현장에서 사용 | 제작 재료의 소모, 인벤토리와 장비 성능의 변화 |

## 루프가 연결되는 방식

- **목적지와 퀘스트 상태.** NPC가 알려 준 목적지는 탐험과 전투에 이유를 붙인다. 현장 결과가 퀘스트 진행에 반영되면, 이후 대화나 다음 목표로 이어질 수 있다. 모든 대화가 세력 관계를 바꾸거나 모든 퀘스트가 전투를 요구하는 것은 아니다.
- **인벤토리와 장비.** 탐험 중 주운 장비는 바로 사용할 수 있고, 수집한 재료는 개조나 건설에 쓸 수 있다. 개조한 장비는 다음 탐험과 전투에서 쓰인다.
- **캐릭터 성장.** 퍽은 어떤 접근 방식에 투자할지 결정하는 수단이다. Bethesda 지원 문서에는 캐릭터의 매력이 정착지 주민 상한에도 영향을 준다고 설명되어 있다. [주민 유입 조건](https://help.bethesda.net/app/answers/detail/a_id/34418/)

## 작은 프로토타입에서 확인할 수 있는 것

| 검증 대상 | 플레이에 필요한 최소 상황 | 관찰할 점 |
| --- | --- | --- |
| 전투 단독 | 짧은 교전과 결과가 달라지는 대응 | 플레이어가 위험을 읽고 대응을 선택하며, 그 결과를 알아차리는가 |
| NPC 상호작용 단독 | 대화 상대 하나, 선택에 따라 구별되는 반응 | 플레이어가 상대의 의도를 이해하고 반응 차이를 알아차리는가 |
| NPC와 전투의 연결 | NPC가 전투에 의미를 부여하고, 전투 결과가 이후 상호작용에 반영되는 짧은 흐름 | 플레이어가 싸운 이유를 자기 말로 설명하고, NPC가 무엇에 반응했는지 연결하는가 |

세 검증 항목은 비교에 사용할 후보이며, 어느 항목부터 만들지는 프로젝트에서 정할 결정이다. 기존 게임에서 살펴본 것은 각 행동의 결과가 다른 행동에 쓰이는 구조다. 출처에는 이 표와 동일한 루프 분류나 프로토타입 검증 절차가 제시되어 있지 않다.
