# Research: 이동 프로토타입 설계 결정

| 결정 | 근거 | 검토한 대안 |
| --- | --- | --- |
| 기존 Unity 프로젝트와 Player/Move 사용 | 프로젝트에 엔진 버전과 키보드·게임패드 바인딩이 설정돼 있다. | 새 입력 에셋은 기존 설정과 중복된다. |
| CharacterController와 평면 이동 | 입력 방향으로 이동하고 해제 시 멈추는 동작을 직접 검증한다. | 힘 기반 이동에는 감속과 관성 조정이 추가된다. |
| 고정 각도의 추적 카메라 | 카메라가 따라가며 화면 기준 이동 방향은 일정하다. | 회전 가능한 카메라에는 시점 조작과 이동 방향 변환이 추가된다. |
| 에디터 Play Mode 검증 | 전용 씬 하나에서 동일 조건으로 재실행할 수 있다. | 별도 실행 파일을 배포하려면 빌드 설정이 필요하다. |
