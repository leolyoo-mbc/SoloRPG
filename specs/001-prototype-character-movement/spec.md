# Feature Specification: 임시 플레이어 캐릭터 이동

**Feature Branch**: 현재 브랜치에서 작성

**Created**: 2026-11-25

**Status**: Draft

**Input**: 임시 캐릭터 이동까지만 다루자.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 임시 캐릭터 움직이기 (Priority: P1)

플레이어는 프로토타입을 열고 빈 테스트 공간에서 임시 캐릭터를 움직여, 자신의 입력에 따라 캐릭터의 위치가 바뀌는지 확인한다.

**Why this priority**: 직접 조종할 수 있는 캐릭터가 첫 프로토타입의 목표다.

**Independent Test**: 프로토타입을 열어 캐릭터를 서로 다른 두 방향으로 움직인 다음, 이동 입력을 놓아 멈추는지 확인한다.

**Acceptance Scenarios**

1. **Given** 프로토타입을 열었을 때 **When** 테스트 공간이 표시되면 **Then** 플레이어가 조종할 임시 캐릭터와 바닥을 화면에서 볼 수 있다.
2. **Given** 임시 캐릭터가 바닥에 서 있을 때 **When** 가능한 이동 방향 중 하나로 입력하면 **Then** 캐릭터가 해당 방향으로 움직인다.
3. **Given** 이동 입력으로 캐릭터가 움직이고 있을 때 **When** 다른 방향을 입력하거나 이동 입력을 놓으면 **Then** 캐릭터가 새 방향으로 움직이거나 제자리에 멈춘다.

### Edge Cases

- 시작 후 이동 입력을 주지 않으면 캐릭터는 시작 위치에 머무른다.
- 이동 입력을 놓은 뒤 다시 입력하면 캐릭터가 멈춘 위치에서 이동을 이어간다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001** 프로토타입을 열면 빈 테스트 공간의 바닥 위에 조종 가능한 임시 캐릭터 하나가 표시되어야 한다.
- **FR-002** 플레이어는 바닥 위에서 이동 방향을 입력하고 바꿀 수 있어야 한다.
- **FR-003** 플레이어가 이동 입력을 놓으면 캐릭터가 멈추고, 다시 이동 입력을 주면 그 자리에서 움직여야 한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001** 한 번의 실행에서 테스트 참가자가 임시 캐릭터를 서로 다른 두 방향으로 움직이고 한 번 이상 멈춘 뒤 다시 움직일 수 있다.
- **SC-002** 테스트 참가자가 이동 입력을 주기 전과 놓은 뒤에 각각 캐릭터가 멈춰 있는지 화면을 보고 확인할 수 있다.

## Assumptions

- 테스트 공간은 바닥과 임시 캐릭터를 확인할 수 있는 단순한 공간으로 충분하다.
- 조작 기기와 시점은 이후 계획 단계에서 정한다.
- 이 기능의 범위는 바닥 위 이동과 정지까지다. 공격, 적, NPC, 캐릭터 외형 제작은 범위 밖이다.
