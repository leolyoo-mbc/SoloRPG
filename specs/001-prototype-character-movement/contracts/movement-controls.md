# 조작과 시야 계약

| 조작 | 키보드·마우스 | 게임패드 | 기대 동작 |
| --- | --- | --- | --- |
| 시선 조절 | Game 뷰를 클릭한 뒤 마우스 이동 | 오른쪽 스틱 | 정지 중과 이동 중에 시선을 좌우·상하로 돌린다. 시선 입력만 주면 캐릭터 위치는 유지된다. |
| 앞뒤 이동 | W/S | 왼쪽 스틱 위/아래 | 화면이 바라보는 수평 방향으로 전진하거나 뒤로 걷는다. |
| 좌우 이동 | A/D | 왼쪽 스틱 좌/우 | 화면 기준으로 좌우 이동한다. 시선 방향은 시선 입력으로 조절한다. |
| 정지 | 이동 키 해제 | 왼쪽 스틱 중립 | 그 자리에서 멈추고, 다음 이동 입력으로 다시 움직인다. |
| 마우스 잠금 해제 | Esc 또는 Game 뷰 포커스 상실 | 해당 없음 | 커서를 해제한다. Game 뷰를 다시 클릭하면 마우스 시선을 사용할 수 있다. |

시작 화면과 바닥 안쪽에서 기본 상하 각도로 이동할 때 캐릭터의 등과 앞쪽 바닥이 함께 보인다. 시선을 위아래로 돌리거나 바닥 가장자리에 접근해도 캐릭터는 화면에 남는다. 위나 아래를 보고 움직여도 바닥 위에서 이동한다. 가장자리에서 바깥으로 밀어도 캐릭터는 바닥을 벗어나지 않으며, 다시 안쪽으로 돌아올 수 있다.
