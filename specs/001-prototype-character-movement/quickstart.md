# Quickstart: Play Mode 검증

1. 구현 후 Unity Hub에서 프로젝트를 Unity 6000.3.26f1로 열고, Project 창에서 `Assets/_SoloRPG/Scenes/MovementPrototype.unity`를 연다.
2. **Play**를 누르고 Game 창에 포커스를 둔다. 바닥과 캐릭터가 보이고 입력 전에는 정지해 있어야 한다.
3. W와 D를 차례로 누른다. 캐릭터가 화면 안쪽과 오른쪽으로 이동하고, 카메라가 각 방향을 따라가는 동안 캐릭터가 계속 화면에 보여야 한다.
4. 키를 놓고 캐릭터가 멈추는지 확인한다. S를 누르면 캐릭터가 멈춘 위치에서 화면 아래쪽으로 다시 움직이고, 카메라가 따라가야 한다.
5. 가장자리에서 바깥쪽으로 계속 이동한 뒤 안쪽으로 돌아온다. 바닥을 벗어나지 않아야 한다.
6. 게임패드를 연결해 왼쪽 스틱으로 이동과 정지를 확인한다. Play Mode를 다시 시작하면 처음 위치에 정지해 있어야 한다.
