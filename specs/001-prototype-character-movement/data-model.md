# Data Model

| 요소 | 상태와 관계 |
| --- | --- |
| 임시 캐릭터 | 시작 위치, 현재 위치, 이동 입력, 이동 속도. 테스트 바닥 안에서 움직인다. |
| 테스트 공간 | 바닥과 이동 가능 영역. 임시 캐릭터 하나를 포함한다. |
| 추적 카메라 | 임시 캐릭터를 대상으로 삼고 상대 위치와 각도를 일정하게 유지한다. |

시작 → 정지. 이동 입력 → 이동. 방향 변경 → 새 방향으로 이동. 입력 해제 → 정지. 재입력 → 현재 위치에서 이동. 경계에서는 바깥쪽 이동을 제한한다. 재실행하면 시작 위치로 돌아간다.
