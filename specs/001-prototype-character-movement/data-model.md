# Data Model

| 요소 | 상태와 관계 |
| --- | --- |
| 임시 캐릭터 | 시작 위치, 현재 위치, 수평 방향, 이동 입력, 이동 속도. 카메라의 수평 시선을 향하고 그 방향을 기준으로 이동한다. |
| 테스트 공간 | 20×20 바닥과 위치 확인용 표식. 캐릭터 전체가 바닥 경계 안에 머문다. |
| 3인칭 카메라 | 추적 대상, 수평 각도, 제한된 상하 각도, 대상 기준 거리와 오른쪽 오프셋. 대상 이동 후 위치를 갱신한다. |
| 시선 입력 | `Player/Look`의 마우스 델타 또는 오른쪽 스틱 값. 마우스 사용 시 커서 잠금 상태를 확인한다. |

Play Mode 시작 시 씬에 지정된 위치와 방향에서 시작한다. 시선만 돌리면 캐릭터와 카메라의 방향이 바뀌고 캐릭터의 위치는 유지된다. 이동 입력을 주면 해당 방향을 수평으로 적용하며, 입력 해제 시 그 자리에 정지한다. 씬을 다시 실행하면 위치와 각도가 시작 상태로 돌아간다.
