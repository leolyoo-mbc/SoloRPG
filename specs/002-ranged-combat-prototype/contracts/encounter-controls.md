# 조작 및 화면 계약

| 상황 | 입력 또는 화면 동작 | 관찰 결과 |
| --- | --- | --- |
| 시작 대기 | Game 뷰 클릭 | 커서가 잠기고 타이머가 시작된다. 클릭 자체로는 발사하지 않는다. |
| 진행 | WASD, 마우스 | 화면 기준 이동과 시선 회전이 동시에 작동한다. 조준점은 화면 중앙에 있다. |
| 진행 | 왼쪽 클릭 | 클릭당 한 발이 즉시 발사된다. 조준점으로 적을 맞히면 상대 체력이 1 줄고 색이 잠깐 바뀐다. |
| 진행 | Esc 또는 포커스를 잃음 | 마우스 조작을 해제하고 교전 시간이 정지한다. 다시 클릭하면 남은 시간부터 재개한다. |
| 적 공격 | 발사 0.5초 전, 발사 순간 | 적의 예고 색을 볼 수 있고 이후 상대 쪽에서 탄이 날아온다. |
| 판 종료 | 한쪽 체력이 0 | 남은 체력과 승패, R 재시작 안내를 표시한다. |
| 판 종료 | R | 양쪽 체력 3과 시작 배치로 복귀하고 새 시작 클릭을 기다린다. |

HUD는 중앙 조준점 및 양쪽 체력과 현재 상태를 표시한다. 안내 문구는 첫 클릭, 정지 후 재개, 결과 후 재시작에 사용한다.
