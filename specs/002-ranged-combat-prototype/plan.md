# Implementation Plan: 원거리 교전 프로토타입

**Branch** — `codex/rpg` · **Date** — 2026-11-25 · **Spec** — [원거리 교전](spec.md)

## Summary

기존 임시 캐릭터와 등 뒤 카메라를 별도 교전 씬에서 재사용한다. 플레이어는 이동하면서 화면 중앙으로 조준해 즉시 발사한다. 고정된 적 한 명은 예고 후 피할 수 있는 탄을 발사한다. 첫 클릭, 교전 종료 및 R 재시작을 한 판의 상태로 관리한다.

## Constitution Check

설계 전과 설계 후에 프로젝트 헌장을 확인했다. 현재 헌장은 초기 템플릿 상태이며 채택된 게이트가 없다. 설계는 기존 프로젝트와 패키지를 사용한다.

### Source Code

- `Assets/_SoloRPG/Scenes/RangedCombatPrototype.unity` — 이동 씬 구성을 복제하고 플레이어와 적을 수평 12m 간격으로 배치한다. 20m 바닥에서는 Z축 -6m와 +6m를 사용한다. HUD와 교전 참조를 씬에 연결한다. 시작 화면에 적이 보이도록 확인하며, 기존 하향 각도 때문에 시작 조준점은 플레이어가 직접 적에게 옮긴다.
- `Assets/_SoloRPG/Scripts/Prototype/` — `PrototypeRangedEncounter.cs`가 입력과 판 상태 및 발사 일정을 조정한다. `PrototypeEncounterProjectile.cs`가 적 탄의 직진과 충돌을 처리한다. `PrototypeEncounterHud.cs`가 상태를 화면에 표시한다.
- 기존 `PrototypeCharacterMovement`와 `PrototypeFollowCamera`를 재사용한다. 카메라에는 조작 가능 상태 및 이번 프레임 마우스 확보 여부를 읽는 속성과, 초기 위치로 되돌린 뒤 본래 yaw와 pitch 및 커서를 복원하는 메서드만 추가한다. 기존 이동 씬에서 호출되는 조작 방식은 유지한다.

## Design

- 교전은 대기, 진행, 승리, 패배 상태를 가진다. 대기 동안 이동과 사격을 막고 마우스 확보 클릭을 소비한다. 진행 중 Esc 또는 포커스 이탈 시 조작과 교전 시간을 멈춘다. 다시 화면을 클릭하면 시간과 조작을 재개하고 해당 클릭은 소비한다. 타이머와 탄에는 교전이 진행 중이고 마우스 조작이 가능한 프레임의 시간만 반영한다.
- 카메라 입력, 캐릭터 이동, 카메라 추적 순서를 유지한다. 교전 컨트롤러는 카메라 추적 뒤 LateUpdate에서 입력을 판정한다. 동일 프레임 양쪽의 마지막 타격이 겹치면 플레이어 발사를 먼저 판정하며, 종료 상태로 전환되는 순간 남은 탄을 제거한다.
- 플레이어 공격은 카메라 중앙을 향한 즉시 판정으로 처리한다. 플레이어 콜라이더는 제외하고, 첫 유효 충돌이 적일 때 1을 차감한다. 명중 색은 본체에 0.15초 동안 표시한다. 발사 예고는 적의 별도 색상 표식으로 표시해 두 표시가 겹쳐도 구분되게 한다.
- 적 탄은 발사 순간의 플레이어 콜라이더 중심을 향해 이동한다. 매 프레임 이동 구간을 구체 스윕해 플레이어와 바닥 충돌을 검사한다. 한 번 충돌하면 제거하며, 빗나간 탄은 5초 뒤 제거한다.
- 종료 후 R은 같은 씬에서 판 상태를 초기화한다. 플레이어 배치 시 CharacterController를 잠시 비활성화하고 위치를 되돌린 뒤, 카메라 시선과 커서를 초기화한다. 새 판은 다시 클릭을 기다린다.
