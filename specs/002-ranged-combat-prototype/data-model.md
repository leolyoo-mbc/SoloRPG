# Data Model: 원거리 교전

| 개체 | 데이터 | 제약 |
| --- | --- | --- |
| 교전 | 상태, 시작 위치와 시선, 다음 적 발사 시각, 소유 탄 목록 | 플레이어와 적은 각각 한 명이다. 대기는 새 시작 클릭을 기다린다. 진행에 들어가면 첫 발사까지 2초를 센다. |
| 플레이어 | 캐릭터 콜라이더, 현재 체력 | 체력은 3으로 시작하며 0~3이다. 결과가 정해지면 체력이 더 감소하지 않는다. |
| 상대 | 고정 위치, 콜라이더, 현재 체력, 예고 및 명중 표시 상태 | 체력은 3으로 시작하며 0~3이다. 예고는 각 발사 직전 0.5초다. |
| 적 탄 | 발사 위치, 방향, 남은 수명 | 발사 시 방향을 고정하고 초속 8m로 직진한다. 한 번만 피해를 주며 충돌, 수명 종료, 교전 종료 시 제거한다. |

대기 → 진행은 마우스 확보 클릭으로 전환한다. 진행 중 조작 미확보는 판을 유지하며 시간만 정지하는 조건이다. 진행 → 승리는 적 체력 0, 진행 → 패배는 플레이어 체력 0으로 전환한다. 종료 → 대기는 R로 전환하며 체력, 위치, 카메라, 일정, 표시와 탄을 초기화한다.
